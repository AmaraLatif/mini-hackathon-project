# Part 2 — Problem and Plan

## 1. Problem
People often do not have easy access to understandable safety information about different areas. Crime information can be scattered, making it difficult for people to understand area-wise risk and take precautions.

## 2. Solution
SafeZone AI is an AI-powered web application that displays area-wise crime risk on an interactive map and provides safety advice for selected areas.

## 3. MVP — Main Features
1. **Interactive Crime Map:** Display crime-related sample data across different areas of Pakistan.
2. **Risk Heatmap:** Show Low, Medium, and High risk levels using different colours.
3. **AI Safety Advisor:** Provide safety scores, risk summaries, precautionary tips, and emergency contacts.

## 4. Tech Stack and Deployment
- Frontend: React.js, Vite, Tailwind CSS
- Backend: Node.js, Express.js
- AI: Google Gemini API
- Map: Leaflet and OpenStreetMap
- Data: JSON
- Deployment: Vercel
- Code Hosting: GitHub
